Knowledge-Based Facebook Customer Support AI Agent

AI agent auto-replies to Facebook customer inquiries in real time using a document-based knowledge base and Google Gemini.

Built an AI-powered customer support agent in n8n that automatically responds to customer inquiries from a Facebook page using a document-based knowledge system. The workflow processes incoming webhook events, retrieves information from connected knowledge base documents, generates context-aware responses using the Google Gemini AI model, and sends automated replies back to customers in real time.

The client's Facebook page was receiving a high volume of repetitive customer questions that required manual replies around the clock. Response times lagged during off-hours, agents spent hours answering the same FAQs, and inconsistent answers were hurting the customer experience.

Designed an n8n workflow that listens for incoming Facebook messages via webhook, pulls relevant context from a connected knowledge base of company documents, and uses Google Gemini to generate accurate, on-brand responses. Replies are sent back to the customer automatically without any human intervention, with fallback logic for edge cases.

Reduced first-response time from hours to seconds, cut manual support workload significantly, and delivered consistent, accurate answers around the clock — improving customer satisfaction while freeing the team to focus on complex escalations

Built an automated pipeline in n8n that scrapes job postings across multiple platforms, uses AI to extract required skills and qualifications, cross-references them against the candidate's existing resume, and generates tailored resume sections, summaries, and ATS keyword recommendations for each application.

Cut resume customization time from hours to minutes per application, improved ATS pass-through rates with targeted keyword alignment, and gave candidates a scalable way to apply to more roles with tailored, higher-quality resumes.

Retrieval Augmented Generationr

RAG system syncs with Google Drive and uses vector search to ground AI answers in company documents, reducing hallucinations.

Developed a Retrieval-Augmented Generation (RAG) system in n8n that enables AI-powered question answering using a centralized document knowledge base. The workflow automatically monitors Google Drive for new, updated, and deleted files to keep the knowledge base synchronized. Documents are processed and converted into vector embeddings using Google Vertex AI and stored in Supabase Vector Store for semantic search. An AI Agent retrieves the most relevant information from the vector database before generating responses. This approach improves answer accuracy and reduces AI hallucinations by grounding responses in actual company documents. The solution provides scalable knowledge management and instant access to organizational information.

The organization's knowledge was scattered across many documents, and generic AI chatbots frequently hallucinated answers or gave outdated information, making it hard for staff to trust or rely on AI-generated responses.

Built a RAG pipeline in n8n that continuously syncs with Google Drive, converts documents into vector embeddings via Google Vertex AI, and stores them in a Supabase Vector Store. An AI Agent retrieves the most relevant document context before generating a response, grounding every answer in verified company knowledge.

Significantly reduced AI hallucinations, kept the knowledge base automatically up to date as documents changed, and gave staff instant, accurate access to organizational information on demand.

n8n, Google Drive, Google Vertex AI, Supabase (Vector Store), AI Agent/LLM

Automated Xero Ledger Report Sync to Asana

Automation pulls Xero transaction data on task completion, formats it as a CSV, and attaches it directly to Asana.

Built a Make.com automation that detects completed tasks in Asana, retrieves transaction-level financial data from Xero using the Account Transactions report as a substitute for the unavailable General Ledger Detail API, formats the data into a downloadable CSV report matching Xero's manual export layout, and automatically uploads the file as an attachment to the completed Asana task.

The finance team needed ledger-level transaction reports attached to completed Asana tasks, but Xero's API didn't expose a General Ledger Detail endpoint, forcing staff to manually pull and format reports for every task.

Built a Make.com workflow that triggers when an Asana task is marked complete, retrieves the equivalent data via Xero's Account Transactions report, reformats it to match the standard manual export layout, converts it into a CSV, and automatically attaches it to the corresponding Asana task.

Eliminated manual report pulling and formatting entirely, ensuring every completed task automatically has an accurate, properly formatted financial record attached — with no workaround needed by staff.

Make.com, Xero API, Asana, CSV Generation
